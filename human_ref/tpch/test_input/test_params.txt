# q1-q22 验证用参数清单(可直接喂给 tools/verify/duckdb_tool.py 的 run_query)

# 参数顺序 = 模板中首次出现顺序, 个数必须严格匹配(run_query 用 strict=True)
# 以 # 开头的行为注释, 逐行喂给 run_query 前请过滤掉
# 重点覆盖: 空结果 / 单行 NULL / 0 行 / 日期月末与闰年归一化 / LIKE 大小写 / 边界值

# ---- q1 (DELTA): interval 减法边界 ----

# ---- q2 (SIZE, TYPE, REGION): like '%TYPE' 前缀通配 ----
# 基准

# TYPE 空串 -> like '%' 全匹配; SIZE 上边界 50

# SIZE 下边界 1; TYPE 给完整值(等值语义)

# TYPE 无匹配 -> 空结果
2 "15" "ZZZ" "MIDDLE EAST"
# SIZE 超出 1~50 -> 空结果

# ---- q3 (SEGMENT, DATE): 双向日期过滤 ----

# 窗口完全越过数据尾部 -> 空结果

# ---- q6 (DATE, DISCOUNT, QUANTITY): between ±0.01 窗口 ----
# 基准

# discount 上边界 0.10(窗口单侧) + qty 上边界 50
